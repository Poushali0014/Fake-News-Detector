**Project Overview**

This project focuses on detecting fake and real news articles using Natural Language Processing (NLP) and Deep Learning 
techniques. A Bidirectional Long Short-Term Memory (Bi-LSTM) neural network is implemented to classify news articles based 
on their textual content.
